# 词典与活用面板布局

Reader 和语法指南顶部工具栏最右侧使用单个按钮选择悬浮气泡或固定布局，图标随当前布局变化。默认使用固定布局：视口宽度不超过 960 px 时显示 bottom sheet，其他宽度显示右侧栏。布局偏好与词条激活态分别管理。

固定布局通过点击胶囊及其成分激活；点击另一查询对象时原位更新，面板持续显示。点击实际内容范围以外或按 `Esc` 退出。modal 与 panel 的退出判断直接使用实际元素边界；sheet 只在把手正上方保留 32 px 防误触区。阅读器的鼠标拖选超过 5 px 后才关闭查询并捕获指针，普通点击更新查询对象时保持激活。

右侧栏占据独立网格列，宽度为 `clamp(340px, 32vw, 400px)`，列宽从零逐帧展开与收回。正文文本宽度预先约束在展开后的阅读区内并保持固定，外围容器宽度随动画变化。侧栏采用纯白表面和边界分隔线，贴合工作区边缘。

bottom sheet 左右各留 12 px，底边贴合屏幕，上方使用圆角。把手区域高 22 px，与下方内容滚动区分开；触摸板滚动只移动内容。词典、活用、接续按自然高度依次排列，统一使用 20 px 内边距、分区标题和横向分隔线，整组内容共用一个纵向滚动区。接续图采用完整高度绘制。

激活或更新查询对象时，抽屉回到词典栏顶部；若高度低于默认词典位置则展开，已展开得更高时保持高度。用户可手动收纳到 80 px 的最低位置。默认高度由词典实际高度确定并受视口高度的 55% 约束；最高位置同时受整组内容高度和屏幕可用高度限制。异步查询的加载阶段保留已有高度。把手支持拖动及方向键，`Home` 收纳到最低位置，`End` 展开到最高位置。

活用表头的内部横线仅在下方有额外内容时显示，内部竖线覆盖整个表头高度。悬浮层代表按钮保留描边的 `layout-panel-left` 三分区图形，矩形及圆角按原尺寸的 80% 定义；顶部增加半幅宽的实心圆角横条，上下区域按 30/70 分配。侧栏使用 `panels-top-left` 的水平镜像，sheet 使用 `panel-bottom-open`。

布局状态入口为 `src/explanation/morphologyLayout.ts`，抽屉测量、停靠和拖动共用 `src/composables/useExplanationSheet.ts`。指南内容经 `ExplanationPopover.vue` 的延迟 Teleport 进入工作区容器；只有已激活的查询创建浮层，目标容器始终存在，避免布局切换时内容留在正文。

## 活用胶囊高亮

正文 token 的点击或悬浮先路由到当前活用详情，再由详情中的 `ConnectionDiagram.sentence` 确定对应的句中图元素。胶囊高亮只消费该路由结果，保存图元素 `unit`、完整原文范围和内部颜色分段；映射在分析数据已经生成后同步完成，不等待气泡绘制或异步查询。

同一点击对象只生成一个高亮背景元素。词干与其后的首个活用假名属于同一对象，蓝色词干和黄色活用部分在该背景内部按原文字符坐标渐变；渐变位置依据字符宽度计算，保持与实际表记一致。后续活用对象严格采用接续图句中节点的范围，每个节点独立路由，合并节点保留全部成员范围。点击同一对象内任意 token 时，整体范围一并激活；前序或相邻对象不因范围相交而亮起。

词干拆分使用 UniDic token、`cType` 和 `cForm`。动词保留五段音便、一段及变格形式的首个活用尾部；形容词及形容词型助动词按 `く`、`かっ`、`けれ` 等实际活用尾部拆分，纯假名、复合词和外来语沿用 token 的完整范围。词干、首个活用假名及后续接续对象均通过同一同步映射接口提供给阅读器和语法指南。

回归审阅以 `M-complex-001~015` 的分析快照为准，逐句核对正文 token、接续图元素和胶囊范围的一一对应关系，并覆盖动词、形容词、缩略、音便、合并节点及多段 `hit_ranges`。验收标准是单一背景元素、无前序误亮、双色边界符合字符宽度、图元素数量与接续节点一致。
