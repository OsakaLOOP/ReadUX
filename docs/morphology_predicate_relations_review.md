# 谓语关系与接续标签审阅

本次按配置中的全部执行器及词性输出类别阅读规则与实现，修改判断规则和句中关系投影。依照用户要求，本会话未执行测试、构建或运行效果验证。

## 判断与谓语身份

だ、で、だった、である、です、だろう、でしょう、なら及形容动词的な、に保留前项词汇类别，并更新词尾对应的活用信息。名词与代词形成名词谓语，形状词形成形容动词谓语。名词谓语借助判断实体身份和实际活用形共享判断词尾接续表，保证后续否定、名词化和其他接续仍有输入依据。

「学生です」对应名词谓语（敬体），「学生だ」对应名词谓语（简体），「綺麗だ」对应形容动词；三者均说明判断作用。连用、过去、推量、条件、连体修饰和连用修饰分别命名。

## 其他类别

| 规则范围 | 审阅后的语义与显示约定 |
| --- | --- |
| 使役、被动、可能、ます、意向、过去 | 保留所属谓语身份，采用相应活用功能；形容词过去仍沿用形容词状态。 |
| ない、たい、やすい、にくい、典型性らしい | 保留明确的形容词性派生与目标活用表，可显示真实的词性变化。 |
| 样态そう与传闻そう | 样态形成判断词干，传闻承接完整命题；箭头分别显示样态、传闻。 |
| よう、みたい、推量らしい、べき、はず、かもしれない | 分别显示比况／推量、当为判断、预期判断、可能性推量；内部接续类别服务后续活用。 |
| の、こと、さ、程度名词 | 显示名词化，并沿用名词接续条件。 |
| て形补助、连用形补助、たりする、になる、くなる | 保留父子链及后项自身词类；连接标明补助接续。になる与くなる继续按变化补助规则处理。 |
| は、だけ、も、とか等插入项 | 保持前项状态，显示插入功能。 |
| 文言形容词与文言助动词 | 使用具体文言活用或助动词功能名称；文语执行状态保留独立活用表。 |

## 静态指南

前端句中关系投影按规则功能识别判断接续，并从链内前置成分恢复谓语身份，可用于展示既有指南数据。后端规则变更参与后续分析，静态分析数据的重新生成由单独的生成流程负责。
