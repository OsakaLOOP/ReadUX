# 活用链重构记录

本轮范围限定为 L2 活用链、补助用言和连用复合动词，以及消费这些结果的活用语法查询目标。惯用句、呼应句和其他表达句式仍由 L3 独立处理。

## 来源判断

UniDic 提供词性、cType、cForm、lemma 和基本表记，负责词形连接许可。GiNZA 提供正式词界和依存图，负责补助用言归属及插入成分的结构核验。补助连接不以 aux 单一标签为成立条件。

本机 GiNZA 5.2.1/ja_ginza 5.2.0 的人工样本结果如下：

| 形式 | 依存结果 |
| --- | --- |
| 读んでおく、读んでいる、读んでみる | て/で --mark--> 前项，补助用言 --fixed--> て/で |
| 读んではおく、读んでもいる、读んでさえみる | て/で --mark--> 前项，插入助词 --case/mark--> 前项，补助用言 --advcl--> 前项 |
| 读み始める、读み切る | 后项为 UniDic 非自立成分；GiNZA 常给 advcl，该标签单独不足以确认复合活用 |
| 读み直す、读み出す | GiNZA 可能合并为一个正式 token，连接由 UniDic 词界与连用形字段决定 |

插入连接因此要求：前项已有 て/で 接续形，GiNZA 存在连接标记到前项的 mark，补助用言存在到同一前项的 advcl/aux/xcomp，每个插入副助词存在到前项的 case/mark。缺少完整依存证据时保留 candidate。

## L2 与 L3

L2 只生成形态链、父链、operator、实际成员范围和来源证据。L3 语法规则消费 L2 的身份与状态，表达句式继续使用声明式规则匹配器。L3 不再承担 て＋补助用言的第二套接续判定。

底层保留 て/で 的 UniDic 词性、活用与连接 operator。补助链的词汇本体仍只包含补助用言 token；MorphologyOccurrence 的构式命中范围在提取层扩展为 て/で＋补助用言，上下文范围继续指向完整父链。该范围用于整体语法命中和展示，不改变词性、词元或查询形。

查询目标对同一补助链只生成一个整体构式目标，例如 ておく 或 ている。父链的 te_connection operator 不再单独生成目标，补助链 operator 负责整体范围；补助用言本体仍可通过链和查询形式单独访问。

## 硬编码覆盖

连用复合动词包括 すぎる、はじめる、つづける、おわる、まくる、だす、なおす、かける、きる、かねる、そこなう、そびれる、とおす、ぬく、つくす。补助用言包括 いる/居る、ある/有る、しまう/仕舞う、おく/置く、いく/行く、くる/来る、みる/見る、くださる/下さる、もらう/貰う、あげる/上げる、くれる/呉れる、やる/遣る、ほしい/欲しい 以及 ごらん/御覧、みせる/見せる 等补充形式。

规则目录位于 crates/readux-core/resources/grammar/source，编译结果位于 crates/readux-core/resources/grammar/compiled。目录规则只负责 L3 的知识身份和可声明条件；L2 的有限状态连接表位于 crates/readux-nlp/src/morphology_machine.rs。假名到 UniDic 汉字 lemma 的适配位于 crates/readux-core/src/language_rules.rs，与 L2 的补助用言身份表保持相同覆盖。
