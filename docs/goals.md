# 开发目标与功能范围

更新日期：2026-11-09。目标依据为用户本次确认的产品方向。文档更新范围与交接要求见[文档更新总计划](documentation_update_plan.md)。

## 项目目标

ReadUX 面向日文阅读中的词汇、活用和语法理解，将分析结果、词典及解说结合到正文交互中。用户可以在桌面端导入书籍或输入文本，在静态 Web 中阅读已发布内容，通过语法指南查看讲解和交互例句。

项目当前最重要的成果是活用分析状态机、配套规则与词条，以及气泡、侧栏、抽屉和 D3 图组件组成的说明界面。后续语言分析以这些成果为参照，依据底层词性、实体身份、活用状态和登记规则，结合 GiNZA 提供的 UD 依存信息，解释正文中的范围、关系和具体用法。

## 当前核心成果

| 成果 | 已有能力 | 主要入口 |
| --- | --- | --- |
| 活用状态机 | 识别词汇核心与功能成分，组织局部接续、状态转换及补助父子链，保存实际词形、规则命中、范围和来源证据 | `crates/readux-nlp/src/morphology.rs`、`morphology_machine.rs`、`linguistic_context.rs` |
| 规则与词条 | 分文件维护执行条件、实体类别、连接路径、变体、原型及展示配置；通过概念关联词条解说和例句 | `configs/unidic-nlp/morphology/source/`、`configs/grammar/`、`crates/readux-core/resources/grammar/` |
| 分析说明界面 | 同一查询对象在气泡、侧栏和抽屉中显示词典、活用与接续说明，支持桌面和窄屏交互 | `src/explanation/`、`src/composables/useExplanation*.ts`、`src/components/explanation/` |
| D3 图与正文联动 | 显示句中活用组成和接续规则树，呈现当前路径、连接器、词类及局部变化，并与正文命中和高亮对应 | `src/reader/morphologyBubble.ts`、`morphologyGraph.ts`、`lookupPresentation.ts`、`ReaderConnectionTree.vue`、`ReaderMorphologyGraph.vue` |

活用规则主要在 `configs/unidic-nlp/morphology/` 维护，词条解说还依赖内置词条和编译后的 grammar 解说资源。资源职责与调用关系见[总体架构](architecture.md)。

## 当前应用入口

| 入口 | 当前用途 |
| --- | --- |
| 桌面端 | 书架管理、EPUB 导入、文本输入、本机分析、阅读与词典查询、活用说明、摘录和笔记 |
| 静态 Web | 读取已发布书籍及其分析、查询资源，按阅读范围加载，保存浏览器中的阅读位置、摘录及设置 |
| 语法指南 | 展示《句法入门》《认识实词、虚词、助词》及活用接续测试课，复用例句分析、查询及说明组件 |
| 开发 CLI 与前端工具 | 检查分词和分析结果，调用会话与查询请求，制作指南和书籍快照，调试页面与图组件 |

桌面端负责本机输入和分析，静态 Web 消费预生成内容。两种入口共用主要阅读及说明组件，资源与数据通过各自的宿主适配访问。具体启动和资源准备见[开发说明](development.md)。

## 后续语言分析方向

| 模块 | 已确定的目标 | 配套结果 |
| --- | --- | --- |
| 词组范围、修饰与并列 | 确定词组整体范围、成员、修饰关系与修饰方法，识别并列等关系 | 准确的模式匹配、用法确定、关系解说及 UI 显示 |
| 格关系与句中成分 | 根据格助词及其身份、用法，结合词组和 UD 信息，确定句中成分及基本依存关系 | 成分及依存对象、具体用法、解说及 UI 显示 |
| 登记语法模式 | 识别、定位和提取已登记语法模式，结合词性、身份、活用与必要的结构条件确定实际用法 | 模式及成员范围、义项或用法、词条解说及 UI 显示 |

三个模块的具体算法、执行顺序、规则格式和代码组织尚待确定。现阶段文档整理应当完整说明可用输入、现有规则及展示基础，记录以上目标和待讨论事项。语言分析文档统一规划在 `docs/language_analysis/`，具体清单见[总计划](documentation_update_plan.md)。

## 后续应用方向

| 方向 | 预期能力 | 当前基础 |
| --- | --- | --- |
| 收藏管理与统计 | 丰富的收藏组织、查询、编辑及统计，关联原文出处、笔记和分析内容 | 当前摘录、笔记、JSON 导出，以及桌面和浏览器的保存接口 |
| Anki 导出 | 从阅读内容与收藏生成适合 Anki 使用的数据 | 当前选择对象、词典结果、解说和摘录导出 |
| 阅读器替换 | 采用 epub.js 或同类方案承接书籍呈现，继续集成正文分析、定位和说明交互 | 当前 EPUB 导入、正文坐标、阅读会话、胶囊及说明组件 |
| LLM 调用 | 在阅读场景中调用 LLM，结合正文和已有分析提供辅助 | 已保留的调用抽象、词典辅助类型及前端端口 |

阅读器方案、收藏模型、统计项目、Anki 交付方式和 LLM 任务范围在后续开发中确定。当前代码中的接口和未接入文件需要按实际引用评估复用价值。
