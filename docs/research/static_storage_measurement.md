# 静态线上化空间测量

测量日期：2026-10-24。采用词典正文与完整语法解说独立挂载、正文及阅读索引按需加载的方式，静态线上化在空间上完全可行。按每千字 80 KiB 的 Brotli 压缩预算，10 万字约 7.8 MiB，现有约 120 万字书库约 93.7 MiB。

## 统计方法

盘点覆盖 8 本书，共 1,199,948 字，字数采用现有书库元数据。分析样本覆盖 5 本书、26 个完整单元、20,190 个正文字符；字符数包含标点与空白，注音读法独立保存。指南覆盖 1.1、2.1 两课，共 132 条例句、1,429 个日文正文字符。

扫描了 881 个缓存文件，其中 4 个缺少查询目标，未用于取样。同文缓存按修改时间选择最近版本，样本分散选取并排除交叠窗口；样本包含 readux v10 和 kotoclip v8 两种分析协议。全书数值由样本估算，文件及压缩体积为实测。压缩参数为 gzip level 9、Brotli quality 9，KiB、MiB 分别采用 1,024、1,048,576 字节。

阅读资源保留正文、注音、胶囊、内外层目标、活用及语法提示，以及完整 matrix_request 查询参数，包含词形、读音、词性约束和词条 ID。词典 HTML 正文、完整语法讲解按共用资源独立计量。

两种组织方式分别为：保留现有投影函数所需词元、活用链和构词对象的“分析对象精简版”，以及预生成胶囊、分组、提示与查询引用的“展示结果预生成版”。后者通过引用共享目标、提示和注音，加载层还原组件所需对象。

脚本使用正式 projectReaderSentence、readerChains、grammarMorphemeLookup 和 chainGrammarLookups 核对精简前后的结果，并核对展示资源序列化还原后的胶囊结构。共 158 份快照通过检查。正式接入需要实现资源加载适配，Vue 组件和虚拟 DOM 结构可以沿用。

## 每千字与全书预算

下表按各书分别压缩，汇总字节数后除以样本字符数。单元通常约 700–900 字，五单元合并约 3,500–4,500 字；样本来自不同位置，用于估算分片大小对压缩率的影响。

| 数据组织 | 原始 JSON／千字 | gzip／千字 | Brotli／千字 |
| --- | ---: | ---: | ---: |
| 分析对象精简版，每单元独立 | 1,245 KiB | 113 KiB | 79.3 KiB |
| 分析对象精简版，每五单元合并 | 1,245 KiB | 113 KiB | 69.3 KiB |
| 展示结果预生成版，每单元独立 | 819 KiB | 83.6 KiB | 65.1 KiB |
| 展示结果预生成版，每五单元合并 | 819 KiB | 83.6 KiB | 57.0 KiB |

展示资源可按每千字 60–80 KiB 规划；80 KiB 覆盖本次两种方案的加权平均值，单个样本存在波动。仅提供 gzip 时，可按每千字 85–115 KiB 规划。

| 文字规模 | 按 60 KiB／千字 | 按 80 KiB／千字 |
| --- | ---: | ---: |
| 10 万字 | 5.9 MiB | 7.8 MiB |
| 30 万字 | 17.6 MiB | 23.4 MiB |
| 当前约 120 万字 | 70.3 MiB | 93.7 MiB |

每次加载 4,000 字约需 320 KiB。1,000 次完整阅读一本 10 万字书，正文及索引流量约 7.6 GiB。词典资源可跨书籍和会话缓存。现有书库图片及附件为 132.3 MiB；阅读资源按宽裕预算计算，书库加附件合计约 226 MiB。

上述压缩体积可作为传输预算。CDN 自动压缩时，源站 JSON 仍占用原始空间；展示格式的全书库原始 JSON 估算约 0.94 GiB，分析对象精简格式约 1.43 GiB。直接托管预压缩对象并设置正确的 Content-Encoding，实际对象存储才接近压缩预算。同时保留 JSON、gzip、Brotli 时，存储按各版本累加。

Brotli 减少约 96.4%，gzip 减少约 91.5%。大型 JSON 已基本紧凑输出，六个文件仅移除排版可减少 63,669 字节，约 0.13%；字段、来源和字符串重复是主要压缩空间。

词典与完整解说独立加载后，两课内容元数据加分析对象精简版为 2.17 MiB 原始 JSON、110.7 KiB Brotli；内容加展示结果预生成版为 1.50 MiB 原始 JSON、96.7 KiB Brotli。指南例句短且重复词汇较多，每千字容量规划采用小说样本。

两课词典快照按现有 occurrence ID 合并去重后有 1,145 个对象，完整正文整体 Brotli 为 0.97 MiB。按约 64 KiB 原始数据切为 322 块，压缩后合计 1.55 MiB，最大一块约 23.3 KiB。分片降低单次查词加载量，压缩率相应下降。

## 实施与复现

建议离线预生成，使用静态对象存储，每本书保存 manifest、章节及图片引用，阅读资源约 4,000–8,000 字一片。词形索引映射到词条 ID 及正文块；语法目标保存概念 ID、出现范围和局部提示，完整讲解按需读取。资源 URL 带内容版本，浏览器复用缓存。现有指南已通过 fetch 读取分析与词典快照，主要改造集中在分片、共享词典和查询入口。

初期使用 Brotli 压缩 JSON 即可满足容量要求，SQLite/WASM 可根据浏览器端检索需求决定。就存储和传输体积而言，静态线上化可行性充分。

脚本为 [Python 入口](../scripts/measure_static_storage.py)和[正式投影及压缩测量](../scripts/measure_static_storage.mjs)，原始字节数见[测量数据](../data/validation/static-storage-summary.json)。执行：

```powershell
python -m pip install --target .agents/analysis/storage-deps msgpack brotli
python -X utf8 scripts/measure_static_storage.py
```

默认读取 Documents/ReadUX Library，可通过 --library 指定书库。中间结果、完整快照及实验数据库位于 .agents/analysis/static-storage；原书库、缓存、词典与应用源码保持只读。
