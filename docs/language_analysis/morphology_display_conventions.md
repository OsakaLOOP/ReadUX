# 活用规则显示规范与修订设计

更新日期：2026-11-09。本文为规则名称、讲解、句中 D3 节点及前接规则树确定统一规范，并记录当前实现与规范的差异。语法细分类别和编写样例见[分类指南](morphology_rule_categories.md)，字段用途及限定集合见 [L5](morphology_configuration.md)。

名称统一已实施：operator的label／title、词条与步骤功能名、句中节点功能名及活用术语采用本页规范。そう按已有证据区分样态／传闻，の／さ按已有concept区分名词化用途。规则条件、rule_group、路径分组、排序与前接卡片编排保持现状，相关设计继续保留为后续项。

## 统一对象和文字职责

读者需要依次看清当前形式、语法身份、具体功能、实际活用和前接条件。同一项内容在词条和图中使用同一术语，各字段分别承担明确的文字职责。

| 对象 | 内容规范 | 形式示例 |
| --- | --- | --- |
| 词条形式 | 当前规则的日语规范形式；来自normalized_form或默认原型 | ている、でした、なければならない |
| 本体词形 | 该成员可查询的词元；补助用言按本体显示 | いる、しまう、くれる |
| 语法身份 | 学校语法或当前构式身份 | 助动词、接续助词、准体助词、补助动词、补助形容词、补助表达、复合语法形式、谓语构式、插入成分 |
| 功能名称 | 简短中文功能名 | 愿望、结果存续、预期、准体名词化 |
| 活用信息 | 本成员当前活用形，必要时附音便或缩约现象 | 连用形 · 撥音便、命令形、词干 |
| 功能摘要 | 一句完整中文，解释形式的意义或作用 | 表示动作正在进行或动作结果持续存在。 |
| 前接分类 | 输入状态的词类分组 | 动词、イ形容词、名词／代词 |
| 前接分支标题 | 区分同类规则的最小信息 | 五段ガ・ナ・バ・マ行、样态、传闻 |
| 前接条件行 | 与机器条件对应的具体许可 | 连用形；后接の／ん；具备な／だ接续资格 |

语法身份采用来源POS和本次构式角色。功能名采用学校语法与实际意义。名词谓语接だ时，节点可显示助动词身份和“断定”功能，前接分类继续为名词／代词。

## 名称与文字的编写约定

`definition.label` 与 `definition.title` 默认采用相同中文功能名。label进入本句操作与步骤，title进入词条用法及句中节点。形式由prototype及normalized_form承担；“活用”只用于整体活用信息，具体规则使用使役、否定、预期等功能名。

多义规则采用能够覆盖已登记意义的简短名称。只有前接路径或evidence已经区分用途时，才采用本句细分名称。例如そう按appearance／hearsay显示“样态”“传闻”；被动／可能尚未确定时显示“被动／可能等”。同一规则的短名称和展开名称保留相同语义范围。

中文说明采用“被动、可能、自发、敬体、过去、完成、断定、推量、样态、传闻、比况、名词化、连体修饰、连用修饰”等用语。代码中的受身、自発、丁寧、接続等既有值在机器字段内保留；用户可见名称使用统一中文。语法形式保留日语，活用范式保留五段、一段、サ变、カ变、ク活用、シク活用、ナリ活用、タリ活用等规范名称。

| 写法 | 规范 |
| --- | --- |
| 同形或意义并列 | 使用全角“／”：样态／传闻、过去／完成 |
| 功能与敬语属性 | 使用中文括号：受惠（自谦）、受惠（尊敬） |
| 成员组合 | 使用“＋”：动词连用形＋たい |
| 实际变化 | 使用“ → ”：しまう → しまっ |
| 活用和现象 | 使用“ · ”：连用形 · 促音便 |
| 一个条件中的补充要求 | 使用“；”：词干；后接の／ん |
| 形式引用 | 正文统一使用「形式」；JSON字符串按协议填写 |

功能摘要说明功能，connection说明接续，formation说明组成，用法和人际条件进入usage_notes等正文。例句应体现该条与相邻规则的区别，例如てある与ている、たい与たがる、にくい与かねる。讲解中的许可范围与机器规则同步审阅。

## 讲解与本句用途的对应

当前主要摘要按concept读取。一份concept可以覆盖多种用法，例如そう的样态／传闻、だ的不同词尾。编写通用摘要时应准确概括整项；本句用途已经确认时，词条功能名、摘要首句和图节点应表达相同用法。

| 规则 | 本句依据 | 本句标题及摘要示例 |
| --- | --- | --- |
| sou_modality | judgement_usage:appearance | 样态：根据外观或迹象判断动作即将发生或性质呈现某种状态。 |
| sou_modality | judgement_usage:hearsay | 传闻：转述从他处获得的信息。 |
| nominalization | 本句concept为grammar.functional.sa | 性质名词化：将前项性质或程度表达为名词。 |
| nominalization | 本句concept为grammar.nominalization.no | 准体名词化：将前项动作或状态作为名词性内容使用。 |
| copula_past | 完整词面为でした | 断定过去：以敬体表达过去的身份或性质判断。 |
| te_ii | 前项含否定，实际为なくていい | 许可／认可：表示前项动作可以省去，即“不必”。 |
| passive_potential | 当前候选尚未完成语义区分 | 被动／可能等：れる／られる可表达被动、可能、尊敬或自发。 |

当前そう依据已有evidence选择样态／传闻标题，并从concept正文的对应definition_list读取本句摘要；缺少具体用途时显示通用摘要。名词化依据concept选择性质／准体名词化名称。其余摘要继续采用已有function_summary及内置词条顺序，上表其他本句摘要作为后续细化目标。概念内容在grammar source中维护。

## 句中 D3 节点规范

句中图描述一次实际出现。节点第一行依次表示功能及本体或原型到实际形式的变化；第二行表示该节点自身的活用。词汇核心显示查询词元及本句词形，连接器和补助本体各自覆盖对应成员。

| 节点对象 | 第一行 | 第二行 |
| --- | --- | --- |
| 词汇核心 | 読む → 読ん | 连用形 · 撥音便 |
| 连接器 | て形接续 て → で | 无活用 |
| 动词性补助本体 | 进行／状态持续 いる → い | 连用形 |
| 过去助动词 | 过去 た | 终止形或连体形，按来源字段 |
| 连体判断词尾 | 连体修饰 な | 连体形 |
| 准体助词 | 准体名词化 の | 无活用 |
| 插入助词 | 插入成分 は | 无活用 |
| 意向形词内活用 | 意向形 読む → 読もう | 意向形 |

相同原型和实际词形只显示一次；音便、缩略标签各出现一次。补助用言的节点采用具体功能名称，“补助动词”等身份在词条中说明。形成多个可见成员的复合词尾，如でし＋た，保留共同语法单元及成员各自词形，功能名称只在该单元首个成员显示。かもしれない沿用已配置的整体节点。

缩约节点保存融合后的实际成员，其原型覆盖相同的语法成分。例如じゃっ是でしまう的缩约活用，节点可以显示“完成／遗憾／感慨 でしまう → じゃっ”，后续た独立显示。词条规范形式继续为てしまう，缩约现象另标“缩略形式”。

词类转换的说明写入功能摘要或活用信息，节点功能仍为愿望、否定等；“动词 → イ形容词”可作为状态变化说明。关系文字统一描述连接，如“补助接续”“判断接续”，具体语法功能由节点给出。当前关系文字主要出现在折行处，位置规则与词义选择分别维护。

名词、代词和普通副词显示“无活用”；ナ形容词的词干显示“词干”；具备审定资格的副词仍保留自身身份，并在资格说明中展示サ变、な／だ、タリ等许可。文言已然形和现代假定形按原始cForm区分；意志推量形在学习显示中统一为“意向形”。

## 前接规则的编排

### 固定分组和层次

前接树按照“输入词类 → 该词类中的差别条件 → 连接器 → 目标形式”组织。名词与代词共享一个展示组，机器categories继续分别保留；其余词类采用下表限定的组名及顺序。

| 顺序 | 规范group | categories对应范围 | 组内细分依据 |
| --- | --- | --- | --- |
| 1 | 动词 | 動詞 | 一段／五段／サ变／カ变，音便，前置使役或被动等 |
| 2 | イ形容词 | 形容詞 | 词干、连用形，ない／たい等具体活用型 |
| 3 | ナ形容词 | 形状詞 | 词干、な／に／で判断状态 |
| 4 | 名词／代词 | 名詞、代名詞 | 词干、判断谓语、经の／な等连接器 |
| 5 | 副词 | 副詞 | する、な／だ、と、タリ资格及本句判断 |
| 6 | 助动词 | 助動詞 | ます等精确活用型；已转换为形容词状态的ない／たい归相应状态组 |
| 7 | 文言用言 | 文語用言 | 具体活用型及其前接形 |

当前group是自由字符串，上述七项是统一设计规定的词汇集合，尚未加入编译器校验。用言、判断、否定、列举、可活用副词等信息改为组内分支条件。名词／ナ形容词等跨组路径可以按真实类别拆分显示，身份与许可范围保持一致。

「たり之后」这类目前只限定previous_operators的路径，需要先确认该操作实际允许的类别，再在对应词类下展示相同条件；学校语法分类不确定时保留待审阅项。组名统一和路径拆分同时核对category兼容关系，逐条确认是否需要exact_category。

### 分支标题与条件行

path.label写“本组中的差别”，steps写“满足该分支的条件”。例如动词组下label为“五段ガ・ナ・バ・マ行”，steps为“连用形；撥音便／イ音便”。目标た／だ已有独立节点时，前接卡片仅说明输入。

| 规则与路径 | 规范分组 | 规范标题 | 规范条件行 |
| --- | --- | --- | --- |
| past/verb_de | 动词 | 五段ガ・ナ・バ・マ行 | 连用形；撥音便／イ音便 |
| past/adjective | イ形容词 | 形容词及ない／たい | 连用形：かっ |
| sou/appearance_verb | 动词 | 样态 | 连用形 |
| sou/hearsay_verb | 动词 | 传闻 | 终止形／连体形 |
| judgement_attributive/noun_nominalization | 名词／代词 | 名词化前接 | 词干；后接の／ん |
| nominalization/no_noun_na | 名词／代词 | 经な名词化 | 词干，经な接续 |
| adverb_suru/suru | 副词 | サ变资格 | 词干；具备する接续资格 |
| adverb_to/to | 副词 | と接续资格 | 词干；具备と接续资格 |
| classical_ri/input0_classical | 文言用言 | サ变 | 未然形 |
| classical_ri/input1_classical | 文言用言 | 四段 | 已然形 |

前接说明应包含具有区分作用的限制，例如な后接の、名词经の接はず、使役后续て形的特殊分支、普通动词与ます的排除关系。input_label只概括整项许可，具体分支的差别由path说明。

`predecessors`声明实际回看的成员数量及顺序，不能因讲解词数改变。共享连接器经connector_paths展开时，规则树保留独立な、て／で或に节点，前项范围引用连接器输入。例如“名词／代词 → な → の”“动词 → て／で → いる”。

### 显示顺序和现有文字依赖

组间使用上表固定顺序，组内按一般活用、音便分支、前置语法操作、特殊后接用途排列；同一用途的变体相邻。当前命中路径保持展开，其他分支由已有展开控件查看。功能和词类分组各有固定位置，避免同一层混排。

当前布局按group文字的正则和localeCompare排序。“助动词”会命中“动词”正则，统一顺序需要同时调整layoutConnectionRules的排序依据。仅重排源paths无法完全控制最终分组顺序。

`steps`当前参与前端的て／で选择：te与contracted_te规则按最后一个step是否恰好为“て”或“で”分支，缩约展开同样读取末项；zuni另有针对ず、に的过滤。因此，统一后的前接条件行需要在投影层与这些结构判断分开处理。实施时先处理该依赖，再整理卡片文字，保留既有路径ID与命中关系。
