## 3. 页面内容

例句卡片只呈现日文例句，以及用户启用中文对照时显示在下方的译文。卡片不附加固定观察说明、来源链接、统计文字或重复的讲解标题。日文范围采用阅读器胶囊及现有解释浮层交互；语法说明由实际生成且已审阅的语法标签提供。原稿知识点由悬浮例句卡片时的段落高亮建立视觉对应。

## 4. 静态内容包

1.1 内容包包含原稿版本标识、Markdown 块锚点、70 条补充例句、19 条原稿例句、插入分组、翻译、词元分析、ruby、教学分类、来源词性、语法标签、活用链与词典查询快照。整体及内部目标保存其范围、关系和浮层所需数据。生成和审阅完成后，前台只读取已加载快照；词典或分析资源变化不改变已保存内容。

后台能够预览并编辑例句标注和快照，保存草稿、标记审阅状态、加载指定版本。原稿、原稿例句表记及 70 条清单作为只读输入。
