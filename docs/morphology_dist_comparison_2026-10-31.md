# dist 静态分析抽样对比（2026-10-31）

当前 `dist/library/catalog.json` 指向《わたしが恋人になれるわけないじゃん、ムリムリ！（※ムリじゃなかった!?）》的 `20261031` 静态版本，共 171 个分析单元。抽取开头、中段与后记的三个完整段落，与当前正式分析服务比较。

三段共 171 个 token、106 条活用链，自动语域路由完全一致。token、实际状态、词形原型、概念、成分范围、父子链、接续路径和查词形式均一致。17 处差异均为 operator 元数据 `output_category` 从“动词”统一为 UniDic 名称“動詞”；`state_before.category` 与 `state_after.category` 的实际词类保持一致。

中段段落：

> その後、乾かしてもらった服を着直したわたしたちは、ホテルを出た。空はウソみたいに晴れ渡っていて、わたしは真唯の言った『晴れてほしいときは晴れて、雨がいいときは雨が降る』という言葉を思い出していた。

## 对比方法

每段均在所属完整单元内重新分析，三个单元的上下文分别为 773、840、876 字符。服务使用 `analyze_routed(policy=auto)`、`enrich` 和 `lookup_targets`，GiNZA 来源就绪后提取对应段落。静态数据与当前结果的原文逐字一致，自动 CWJ／CSJ 路由一致。

比较 token 的表记、词性、词元、读音、范围与查询形式；比较活用链的状态、原型、范围、停机状态、父子关系及 operator 字段；比较 connection 的 rule、path、matched_paths、前项范围和诊断；比较内外层查询目标的范围、表记、查询形式、决定与原因。文档 ID、运行计时和服务信息独立于语言结果。

复现入口为 [compare_morphology_dist.py](../scripts/compare_morphology_dist.py)：

```powershell
npm run morphology:build
cargo build -p readux-core --bin readux-nlp
python -X utf8 scripts/compare_morphology_dist.py
```

完整机器比较结果位于 `.agents/analysis/morphology-dist-comparison.json`，保存每段的来源单元、全书坐标、前后投影及逐字段差异。比较过程读取 dist 中的静态数据，重新分析结果写入独立报告。
