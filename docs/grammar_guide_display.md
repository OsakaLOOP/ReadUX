# 语法指南展示与交互设计

状态：设计稿，待实施。范围：基于现有词典、UniDic／GiNZA 分析结果和活用链，完成语法指南页面及例句交互。首个交付章节为 [1.1 认识实词、虚词、助词](grammar_guide_1_1.md)。

## 1. 产品目标与内容组织

页面以中文 Markdown 讲解为主体，在对应论点之后插入可交互的日文胶囊例句。用户能够阅读论点、观察例句中的成分、查询词典并查看已有活用过程。固定教材例句的教学分类、关注范围和说明由内容编辑确定。

指南入口位于现有文法库，增加“语法指南”视图；知识条目详情可以链接到指南的具体小节。指南采用左侧章节目录、中央正文、正文内例句的布局，窄窗口将目录折叠为按钮。返回目录或查词后恢复原阅读位置。

## 2. Markdown 与胶囊混排

### 2.1 内容文件

建议新增 `content/grammar-guide/`，每课由一个 Markdown 正文和一个例句 JSON 文件组成，目录表保存稳定课节 ID、标题及顺序。1.1 的稳定 ID 为 `guide.word-classes`，页面显示编号仍为“1.1”。文件名、课节 ID 和页面编号分别承担定位、引用和导航职责。

普通 Markdown 支持标题、段落、加粗、列表、引用、表格、链接和代码。专用 fenced block 在 Markdown AST 中转换为 Vue 例句组件：

````markdown
实词和虚词在句中具有不同的作用。**补助用言**可以为动作添加持续、尝试等意义。

```readux-examples
{"point":"P06","examples":["E20","E21"],"layout":"list"}
```
````

`point` 是本课知识点 ID，`examples` 引用同课例句记录，`layout` 支持 `paragraph`、`list`、`contrast`。每组紧随对应说明；长段落含多个知识点时拆为连续的说明与例句组。常规 Markdown 列表中的日文引用保持普通文字，教材例句统一通过上述块嵌入。

编译时保留 Markdown AST，专用块输出组件节点。可采用 `markdown-it` 并关闭原始 HTML；当前 `package.json` 尚未声明 Markdown 渲染依赖。链接只接受有效内部课节锚点及允许的网页地址。例句块的 JSON 解析和字段校验在内容加载／构建阶段完成。

### 2.2 例句结构与范围

以下为新增内容协议；已有分析结果作为例句运行数据引用。

```ts
type TeachingClass = "content" | "functional" | "particle" | "other";
type GuideSpan = {
  id: string;
  range: [number, number];
  quote: string;
  teachingClass?: TeachingClass;
  subtype?: string;
  note?: string;
};
type GuideExample = {
  id: string;
  ja: string;
  zh: string;
  contextBefore?: string;
  focus: GuideSpan[];
  annotations: GuideSpan[];
  ruby: { range: [number, number]; base: string; reading: string }[];
};
```

`ja` 是纯日文原文，中文、编辑说明、显示分隔线分别保存。`focus` 指本段论点需要突出观察的范围，`annotations` 保存教学分类和本例解释，二者允许引用相同范围。全部范围采用例句内 Unicode scalar 半开区间；必须满足 `quote === Array.from(ja).slice(start, end).join("")`。相同词语重复出现时通过范围区分。

每个例句拥有独立出现身份。同一文本可以共享分析缓存；例句 ID、译文和教学重点保持独立。上下文参与分析时，保存例句在分析文本中的偏移；前端映射后只渲染例句正文。上下文变化参与缓存标识。

### 2.3 排版规则

段落模式适合单句或完整例段；列表模式适合逐项观察；对照模式用于实义／功能用法等两列对照。日文行在上，译文在其下方；例句编号和短说明位于正文之外。对照组在窄窗口改为上下排列，顺序及对照标题保持一致。

教学重点用下划线或浅底显示，类别通过细色条和文字标签区分。既有胶囊轮廓、查询命中与活用范围继续承担交互反馈。每组显示简短图例“实词、虚词、助词、其他”；悬浮或键盘聚焦时显示该范围的具体类别。颜色以外保留文字与边线区别。

一个阅读胶囊可以同时含实词、虚词和助词。分类作用于内部有效范围，胶囊外框表示阅读分组。`食べている` 内部可以显示 `食べ〔实词〕`、`て〔助词〕`、`いる〔虚词〕`，整句查询和各成分交互保持可用。

正文行自然换行，译文与说明使用 `overflow-wrap`，控件允许换行。长句在可用宽度内分行，日文 ruby、胶囊边线、焦点外框均计入行高。1.1 页面保持横排，适配 360 CSS px 的内容宽度与 200% 缩放。

## 3. 交互与显示设置

### 3.1 查词与活用

悬浮、点击固定、整体及内部成分选择、词典与表记切换沿用正式阅读器的行为。教学说明和已有活用详情在同一解释容器中分区显示，当前词形、词典结果和教材指定用法都有明确标题。固定表达的编辑注释可以覆盖多个词元，各词典目标仍通过原有范围命中。

例如「食べてみた」中的「みた」显示“虚词 · 补助动词”，活用栏沿用「みる」及「た」的既有链信息；「食べてみた」的教材说明为“尝试吃了一下”。点击词典入口查询「みる」对应记录，具体表记继续由词典矩阵提供。

例句区域具有自己的查询作用域，键为课节、例句、分析版本和目标 ID。不同例句中的相同位置、相同词语不会共用打开状态。离开例句、关闭页面或切换章节时按现有查询生命周期取消请求；迟到结果核验该作用域后更新。

键盘 Tab 到达交互成分，Enter／Space 固定解释，Esc 关闭，焦点回到来源成分。解释容器中的词典操作保持可达。标点、译文和 Markdown 代码块按各自文本语义处理。

### 3.2 中日对照

页面顶部提供“中文对照”开关，默认开启；作用于本课全部例句及对照列表。每个例句组可提供同名局部开关，局部状态优先；页级开关操作时清除局部覆盖并统一设置全部组。

开启时按“日文行 → 中文译文 → 简短观察说明”排列。关闭时隐藏中文译文，保留教学说明与类别图例。多句例段按句对齐，译文跟随对应日文句；整段意译须在例段记录中声明为段级译文。

### 3.3 全词注音

“假名”开关同样支持页级与例句组级，默认开启。开启后对所有具有有效读法的日文词语显示 ruby，包括已知词；汉字词按可验证的汉字／送假名对齐显示，纯假名词和片假名词使用整体词范围作为 ruby base。纯假名词的 ruby 可以与原文相同，以满足全词注音的字面要求。标点、空白保持原样。

本课 ruby 使用现代日语假名读法，`東京→とうきょう`，`食べて→たべて`；助词 `は／へ／を` 显示书写假名读法，其实际发音在词典或教学说明中解释。发音字段如 `pron` 中的长音表示与词元读法各自保留。优先级为本课经核验的作者注音、对应出现形式的 `kana` 及既有注音对齐结果；其他来源读法经过对应范围核验后使用。

「全词注音」是指南的显示模式。正式阅读器当前的 `readerRubyAnnotations` 主要投影作者注音及校验结果，指南需要增加全词读法投影。关闭时移除／隐藏 `rt`，词典目标、教学范围和查询身份保持稳定。

分类与注音、译文开关只改变展示，复用分析与词典结果。开关后重新测量例句高度及浮层位置；以例句 ID 和局部位置维持视口锚点。偏好采用指南独立设置保存，初始值如上。

## 4. 术语与教学分类

### 4.1 三种信息的呈现

| 信息 | 例子 | 显示位置 |
| --- | --- | --- |
| 教学分类 | 实词、虚词、助词、其他 | 胶囊内部范围、图例和解释首行 |
| 可读词类／功能术语 | 动词、助动词、补助动词、形式名词、格助词 | 解释首行及简短标签 |
| 分析器原值 | `動詞-非自立可能`、`AUX`、`Inflection` | “分析标签”折叠区域，按来源分行 |

“补助用言”是功能总称，包含补助动词和补助形容词；“助动词”对应词法类别。日文 `補助動詞` 与 `助動詞` 采用各自术语。`非自立可能` 显示为“可作非独立用法”，保留可能性含义。教材正文按具体例句显示“补助动词”等实际用法。

`AUX` 的中文来源标签为“辅助成分（UD）”，其日语覆盖面包含助动词和部分功能用言。`ADP` 在日语中显示为“后置词（UD）”。`VERB` 显示“动词（UD）”。教学类别另外显示，来源标签与教学术语各有明确名称。

### 4.2 UniDic 基础映射

映射以完整层级值匹配，保留 pos1–pos4。表内“基础归类”服务于教材展示；上下文用法由既有活用链和本课标注细化。

| UniDic 标签或范围 | 中文术语 | 基础归类 | 本课处理 |
| --- | --- | --- | --- |
| `名詞-普通名詞-一般`、`名詞-固有名詞-*` | 普通名词、专有名词 | 实词 | 形式名词用法由例句标注覆盖 |
| `代名詞`、`名詞-数詞` | 代词、数词 | 实词 | 数量表达保留已有整体与内部查询 |
| `名詞-普通名詞-副詞可能` | 名词（可作副词） | 实词 | 「昨日」等显示本句副词性用途 |
| `名詞-普通名詞-サ変可能` | 名词（可接する） | 实词 | 结合已有词典整体、词汇链显示「勉強する」 |
| `名詞-普通名詞-形状詞可能`、`サ変形状詞可能` | 名词（可作な形容词／可接する） | 实词 | 显示词法可能性和本句用法 |
| `動詞-一般` | 动词 | 实词 | 复用词汇活用链 |
| `動詞-非自立可能` | 动词（可作非独立用法） | 按出现用途确定 | 词汇核心为实词；功能链核心或编辑指定补助用法为虚词 |
| `形容詞-一般` | い形容词 | 实词 | 抽象状态词仍归实词 |
| `形容詞-非自立可能` | い形容词（可作非独立用法） | 按出现用途确定 | 「本がない」与否定补助用法分别标注 |
| `形状詞-一般`、`形状詞-タリ` | な形容词词干、タリ形容词词干 | 实词 | 如「静か」「堂々」；来源原值保留 |
| `形状詞-助動詞語幹`、`名詞-助動詞語幹` | 助动词词干 | 虚词 | 「そう」「よう」按本例说明具体功能 |
| `副詞`、`連体詞` | 副词、连体词 | 实词 | 「ゆっくり」「この」保持实词类 |
| `助動詞` | 助动词 | 虚词 | 显示否定、过去、礼貌等已有活用信息 |
| `助詞-格助詞` | 格助词 | 助词 | 来源细类保留；作用范围由教材标注 |
| `助詞-係助詞` | 系助词（话题／提示） | 助词 | 「は」显示话题或对比；并列「も」另注具体用途 |
| `助詞-副助詞` | 副助词 | 助词 | 「だけ」等显示范围限定意义 |
| `助詞-接続助詞` | 接续助词 | 助词 | 「て」等保留现有链中连接范围 |
| `助詞-準体助詞` | 准体助词（名词化） | 助词 | 如来源将「の」标为此类，展示名词化用法 |
| `助詞-終助詞` | 终助词 | 其他·语气 | 与 1.1 对边缘类别的说明保持一致 |
| `感動詞-*` | 感动词／应答词 | 其他·应答感叹 | 「はい」「ああ」按词典细类显示 |
| `接続詞` | 接续词 | 其他·篇章连接 | 采用指南的篇章功能归类 |
| `接頭辞`、`接尾辞-*` | 前缀、后缀及具体派生类型 | 其他·构词成分 | 已有词汇整体显示整体词类；原子仍可查询 |
| `補助記号-*`、`記号-*`、`空白` | 标点、符号、空白 | 其他·非词语 | 保留排版；图例统计按词语范围计算 |
| 来源新增值、未知词 | 来源术语或“词类待定” | 其他·待定 | 教材发布前为关键范围完成编辑标注 |

“其他·语气”和“其他·篇章连接”是本指南的教学分组；来源词类继续显示终助词、接续词。复合助词是多个原子成分组成的教学整体，保留成员词性。

### 4.3 GiNZA 标签对照

GiNZA 在当前适配器中使用 `features.pos` 保存 UPOS、`features.tag` 保存细粒度标签；后者来源于 Sudachi 的词类体系，字段与 UniDic 有相似之处，来源身份分别保存。

| UPOS | 中文来源标签 | 教学映射的使用方式 |
| --- | --- | --- |
| `NOUN`、`PROPN`、`PRON`、`NUM` | 名词、专有名词、代词、数词 | 支持实词基础映射；形式名词按本例用途 |
| `VERB`、`ADJ`、`ADV`、`DET` | 动词、形容词、副词、限定词 | 结合细类和词汇核心；限定词对应本例连体词等用法 |
| `AUX` | 辅助成分 | 结合细类区分助动词、补助用言、助动词词干及词汇构词成分 |
| `ADP` | 后置词 | 日语助词的来源支持，具体名称采用细类及教材用法 |
| `PART` | 小品词 | 本例可为终助词等，按细类分配教学类别 |
| `SCONJ`、`CCONJ` | 从属连接成分、并列连接成分 | 细类为助词时按助词处理；接续词按其他·篇章连接处理 |
| `INTJ` | 感叹／应答词 | 其他·应答感叹 |
| `PUNCT`、`SYM`、`SPACE`、`X` | 标点、符号、空白、未分类 | 其他对应子类 |

「いる」的 `VERB/AUX` 对照适合作为教材观察例，但页面显示实际来源值。固定例句的教学类别可以依据编者说明确定，分析标签区域展示该次分析结果。GiNZA 缺席时依靠 UniDic、词典、已有链及教材标注完成本课。

来源词界与教学范围存在多对多关系时，通过现有对齐结果关联，展示完整来源 token 及其覆盖范围。局部相交的 token 标明“部分覆盖”，原始词性按完整 token 展示。

### 4.4 本课分类的决定顺序

1. 使用与正文范围及文本版本核验一致的例句教学标注。固定例句中的形式名词、补助用言、复合助词和例外均可直接指定。
2. 对未显式标注部分，复用现有活用链中已确定的词汇／功能核心、词典整体和构词成员归属。
3. 使用 UniDic 基础词性映射；需判断上下文的“非自立可能”等值等待已有归属或教材标注。
4. GiNZA 标签提供已对齐的补充信息；存在分歧时分别展示来源。剩余范围显示其他·待定。

例句教学标注只影响本例的显示与说明。已有词典目标、活用链和来源原值保持各自身份。实现只需“标签映射、已有归属读取、固定例句标注”三项展示能力。

整体和原子分类分别保存：「勉強する」整体为实词动词，其构词成员在详情中显示；「静かな」整体为实词な形容词，其「な」显示为已有链的连体活用；独立出现的判断助动词「だ」采用虚词类别。「食べた」整体词汇核心为实词，「た」作为过去助动词在内部显示虚词。来源字段始终可以查看。

### 4.5 原稿术语的统一建议

| 原稿内容 | 本稿采用的教材表述／处理 |
| --- | --- |
| 汉字／假名规律“70% 以上” | 采用“常见书写倾向”，删除无语料依据的比例；加入假名实词、汉字功能用法例句 |
| 实词意义“独立可理解”、虚词有确定指代集合 | 词汇义可单独查考；语法义可解释，具体解读和接续对象由上下文确定 |
| 实词可“单独成句” | 明确部分实词及适当活用形式可独立成句；词类判断同时观察用法 |
| 虚词“必须附属于实词后” | 采用“依附于词汇核心或前接结构，为整体添加语法意义”；覆盖形式名词接续小句 |
| 助词“大多数没有实际含义” | 采用“表达格关系、话题、限定、连接等语法意义”；「だけ」配意义明确的例句 |
| 自立语／附属语以“能否独立成句”为唯一标准 | 学校文法主要按能否独立构成文节区分，再按活用等细分；提供同句对照 |
| 正文将终助词等作为边缘，表 1／2 又收入助词或感动词 | 首期统一为其他·语气／应答感叹；来源词类保留，2.1 可从使用功能集中讲解 |
| 表 1／2 将「だ」列为终助词 | 本课统一为虚词·判断助动词；句末位置另作功能说明 |
| 「いる」“规范始终写作假名” | 正文采用常见「いる」，词典可显示「居る」表记；书写线索与词类用途分别观察 |
| 同行使用「付く／席に着く／について」 | 同词元对照改为「服に泥が付く／この問題について話す」；「席に着く」作为不同词元说明 |

## 5. 分析复用、运行状态与实现划分

建议组件边界为 `GrammarGuideView`（目录与偏好）、`GrammarGuideArticle`（Markdown AST）、`GrammarExampleGroup`（译文与布局）、`GrammarExampleSurface`（共用胶囊投影与查询）、`GrammarAnalysisLabels`（教学术语与来源标签）。组件数量可按现有提取结果调整，职责以本段为准。

指南加载正文和例句元数据后，优先请求可见例句及相邻组的现有分析。复用现有分析单元、词典查询和活用缓存；教学注释及译文独立于分析产物。Markdown 编辑仅更新排版；日文或上下文变化更新对应分析；教学范围变化重新核验内容投影。

| 状态 | 页面行为 |
| --- | --- |
| 分析中 | 显示日文、中文和编辑重点，例句旁显示简短进度 |
| 基础分析完成 | 启用可用词典目标、来源词类与注音 |
| 活用结果完成 | 启用对应形态详情；请求完成后核验例句与版本 |
| 单例分析失败 | 保持原文与教学内容，提供该例“重试” |
| 词典无记录 | 显示已有词类、活用和教材说明，并明确查询结果 |
| 编辑范围失配 | 内容校验报告具体例句及范围；发布前修正；开发预览显示原文 |

教程浏览使用独立临时文档上下文。书籍阅读进度、曝光统计等记录继续由原阅读入口管理。
