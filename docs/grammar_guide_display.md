## 1. 原稿与内容组织

讲解正文逐字采用 `D:\DCMT\dev notes\ReadUX 日文语法指南.md`，保留原稿的措辞、加粗、表格、例子、旁注、章节顺序和分类表述。例句通过独立插入配置与原稿混排。例句卡片不含固定讲解文字，语法说明来自已生成的语法标签。

指南入口设于现有文法库，页面由目录、Markdown 正文和可交互例句组成。正文按原有顺序呈现，例句紧随对应知识点；同一长段中的多个知识点可以在原句边界处插入例句组，原文内容连续保留。原有表格的日文例子可以绑定交互胶囊，其文字和排列保持原样。

后续内容支持词语和活用、助词和文节、黏着表达、小句、篇章、UD、话语交际及学校文法对照。当前仅设计这些内容共同需要的展示形式：段落、列表、对照表、词语与多成分范围的交互。首期完成 1.1。

## 2. 固定 JSON 内容包

### 2.1 提前生成与前台加载

制作流程为“原稿及例句输入 → 调用现有词典、UniDic／GiNZA、活用链 → 生成 JSON 草稿 → 后台审阅和修改 → 保存 → 前台加载指定版本”。

胶囊的所有展示和交互信息提前保存为 JSON，包括日文、译文、分组、内部成分、ruby、词性、教学分类、中文术语、来源标签、活用链及步骤、词典内容与表记选项、重点范围、悬浮／点击目标及目标间关系。前台读取保存的最终值，执行排版、开关和交互；分析器、词典和映射配置更新后，已保存内容保持稳定。

每课采用一个内容包，包含原稿正文、插入位置和例句数据。后台保存草稿与已加载版本，用户选择“加载”后前台使用对应版本。重新生成选中的例句时先形成草稿，既有人工修改和已加载版本继续保留，审阅时决定采用哪些生成结果。

### 2.2 数据内容

| 内容 | JSON 保存的数据                                                        |
| ---- | ---------------------------------------------------------------------- |
| 课节 | ID、标题、原稿 Markdown、顺序、内容版本                                |
| 混排 | 原文插入锚点、例句 ID、段落／列表／对照布局                            |
| 例句 | 日文、中文译文、原稿关联和显示范围                                     |
| 胶囊 | 分组范围、内部片段、显示文字、重点、类别与颜色角色                     |
| 注音 | 每个词的 ruby base、假名和范围，保留作者指定读法                       |
| 标签 | 原始词性和来源、本句教学类别、可读术语、简短说明                       |
| 活用 | 基本形、查询形、表面形、连接形、完整步骤及步骤说明                     |
| 词典 | 整体及内部目标、词典条目正文、词头与读音、表记矩阵、默认选项和关联条目 |
| 交互 | 命中范围、默认目标、可选内部目标、详情引用和关系导航                   |
| 审阅 | 草稿／已审阅状态、人工修改后的内容、版本和生成来源记录                 |

词典正文、活用说明和语法标签均保存实际展示值。条目 ID、concept ID 和资源版本用于追溯；前台按 JSON 中的内容及引用显示。条目内链接指向内容包已保存的关联内容。生成时缺少的词典结果保存为无记录状态，前台不添加替代讲解。

内容包内共用词典记录和详情可以集中存放，以 ID 引用。前台加载范围可以按课节或例句组划分，所有引用均指向该保存版本。

### 2.3 结构示意

以下为数据组织示意，具体胶囊及词典内容由现有结果转换并在后台修改。

```ts
type GuidePackage = {
  lessonId: string;
  version: number;
  status: "draft" | "reviewed";
  sourceMarkdown: string;
  placements: {
    anchor: string;
    examples: string[];
    layout: "paragraph" | "list" | "contrast";
  }[];
  examples: GuideExample[];
  details: Record<string, GuideDetail>;
  dictionaryEntries: Record<string, SavedDictionaryEntry>;
  generatedFrom: Record<string, string>;
};
type GuideExample = {
  id: string;
  ja: string;
  zh: string;
  note: string;
  capsules: {
    id: string;
    range: [number, number];
    parts: {
      range: [number, number];
      text: string;
      teachingClass: "content" | "functional" | "particle" | "other";
      classLabel: string;
      term: string;
      focus: boolean;
      detailId: string;
    }[];
  }[];
  ruby: { range: [number, number]; base: string; reading: string }[];
  targets: {
    id: string;
    range: [number, number];
    detailId: string;
    defaultEntryId: string | null;
    entryIds: string[];
    childTargetIds: string[];
  }[];
};
```

`GuideDetail` 保存标签、来源原值、活用链及完整说明；`SavedDictionaryEntry` 保存词典身份、词头、读音、可渲染正文、表记选项及包内关联。例句范围沿用项目的 Unicode scalar 半开区间。前端由范围完成命中，屏幕位置随实际排版计算。

## 3. 后台审阅与编辑

后台提供课节列表、例句列表和与前台一致的预览。审阅者可以逐例修改日文、译文、胶囊分组、ruby、重点范围、教学类别、术语、来源标签、词典快照、活用步骤和交互目标，保存为可继续加载的 JSON。

原稿正文在审阅界面只读。原稿内例子绑定的日文同样保持原文；审阅者调整其胶囊信息。新增例句的内容可以编辑。

操作保留“生成草稿、保存、标记已审阅、加载”四项。加载时采用保存后的完整版本，预览与前台共用组件。生成失败在后台显示对应例句与重试入口，前台继续使用已加载版本。后台可以直接打开和保存内容包 JSON，支持离线修改后的重新加载。

生成阶段完成基本词法、词典与活用结果的转换，并记录所用资源版本；后台编辑决定最终展示数据。日文修改后，对应范围、注音和目标由后台一并调整或重新生成。载入只检查 JSON 可读取、引用可解析和范围对应，提示具体位置供编辑修正。

## 4. Markdown 与胶囊交互

原稿 Markdown 使用保留加粗、链接、列表、引用和表格的渲染方式。插入配置独立于正文，渲染时在指定位置加入例句组件。例句组支持段落、列表和对照排列；窄窗口中对照组上下排列，胶囊和控件自然换行。

悬浮或点击例句成分时显示生成并审阅后的语法标签、词性、词典和活用详情；每项交互从内容包的目标与快照取得数据。例句卡片不显示固定观察说明、统计文字或显式知识点链接。

页面提供“中文对照”和“假名”开关，控制当前课节的全部例句。中文显示在对应日文下方，ruby 使用内容包保存的全词注音。例句组可以单独开关；页级操作统一更新全部组。两种开关只影响显示。

分类以内部范围呈现，一个胶囊中可以同时包含实词、虚词和助词。图例采用“实词、虚词、助词、其他”，具体成分同时显示可读术语，来源原值可展开查看。重点样式与当前查询反馈分别显示。

编号 日文例句 中文对照 语法或词语要点
07 窓を開ける。 打开窗户。 開ける：实词·动词，本句表示打开有开合结构的物体。
08 旅行のために三日間、予定を空ける。 为了旅行，空出三天时间。 空ける：实词·动词；与 07 同读「あける」，表记和本句意义不同。

10 雨。 下雨了。 场景：走到门口，看见外面下雨。雨为实词·名词，可在该语境中形成简短话语。
11 急げ！ 快点！ 急ぐ的命令形；整个词构成命令句，显示基本形与命令形。
12 おいしかった！ 真好吃！ おいしい：实词·い形容词，独立表达评价。
13 子供たちは希望を持っている。 孩子们怀有希望。 希望：实词·抽象名词；持っている另显示词汇核心与功能成分。
14 赤ちゃんが眠っているので、そっとドアを閉める。 宝宝睡着了，轻轻地关上门。 そっと：实词·副词，修饰閉める，表达动作方式。
15 この道はとても狭い。 这条路非常窄。 とても：实词·程度副词；狭い：实词·い形容词。
16 京都に行きたい。 想去京都。 行き：实词，基本形行く；たい：虚词，为动作增加愿望意义。
17 今夜は出かけない。 今晚不出门。 出かけ：实词，基本形出かける；ない：虚词，为动作增加否定意义。
