# 谓语接续例句验收

日期：2026-10-27。使用真实 CWJ UniDic、正式 `AnalysisService` 与 `readux-nlp stdio`，检查形态接续、父子链、查询原形和语法概念。用户撤回的缺失助词例句已移出测试与开发范围。

## 问题与处理

「しかない」「意向形＋とする」「こと」名词化和「ていい」缺少连接规则，已成立的局部活用链在这些位置分离。「てかかる」「ていただく」缺少补助本体配置，后续活用可识别，前项归属缺失。规则集中于 `configs/unidic-nlp/morphology.json`，继续使用既有执行器。

「しか＋ない」作为连续词尾识别，head 读取「ない」的实际词形，输出形容词状态。后续否定保留独立作用范围。「意向形＋と」要求后接「する」，随后建立补助子链。「こと」依据名词身份、词元及前项连体形完成名词化，查询原形继续归属前项，后接「に＋なる」。

「ていい」承接用言て形，输出后项形容词活用状态；「考えなくていい」中的否定属于「考える」。补助「かかる」表示以前项所示态度应对某事，词汇核心为「舐める」，「かかる」继续连接「ている」、过去和推量。原始 UniDic 动词词性保留在来源中，补助身份记录为功能成分和父链。

「そうになる」和「置いていかれないように」的形态连接已成立，本轮作为完整句回归；词汇查询分别指向「投げ出す」「置く」，「集中する」保留独立谓语。

## 七句结果

| 输入 | 形态接续与查询结果 |
| --- | --- |
| もうファンになっちゃうしかなくない | ファン＋に→なる→ちゃう→しかなく→ない；「しかない」与后续否定分开保存，名词查询指向ファン。 |
| 屋上から投げ出されそうになった | 投げ出す→受身→そう→に→なる→过去；词汇查询指向投げ出す。 |
| 場所を作ろうとしているからな | 作る→意向形＋と→する→ている→から；句末な独立，三个动词形成连续父子链。 |
| 順番に達成していくことになる | 達成する→ていく→こと名词化→に→なる；こと与前项同链，なる建立子链。 |
| 　置いていかれないように集中した | 置く→ていく→受身→否定→よう→に；集中した独立，开头全角空白保持边界。 |
| 考えなくていいんだから | 考える→否定→て→いい→ん→だ→から；词汇查询仅保留考える，いい为补助子链。 |
| 舐めてかかっていただろう | 舐める→てかかる→ている→过去→だろう；かかる为态度补助，词汇查询仅保留舐める。 |

七句全部为 resolved，形态诊断为空。测试逐项核对目标规则、父子关系、查询原形、命中区间及新规则对应的讲解入口；原始词性、功能身份与语法概念分别保存。

## 验证

真实分词测试位于 `crates/readux-core/tests/p4_language.rs`：`supplied_predicates_keep_constructions_and_local_boundaries` 覆盖七句、局部屈折和查询，`attitude_and_humble_support_preserve_recursive_inflection` 覆盖态度补助与通用授受例句。对照覆盖普通引用、独立动词、同音词，以及标点、空白造成的连接边界。

通过 `cargo test -q -p readux-nlp` 的 80 项测试、`cargo test -q -p readux-core --lib` 的 55 项测试、`cargo test -q -p readux-core --test p4_language` 的 13 项测试及阅读器活用展示的 19 项测试。语法目录由 `scripts/build_grammar_catalog.py` 生成并检查，CLI 已重新构建。
